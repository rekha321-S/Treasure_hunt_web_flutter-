# 🏴‍☠️ Treasure Hunt Web - Flutter

An interactive 3-level web-based treasure hunt game where users solve clues to progress to the next level.

### 🎮 How It Works:
- Level 1: Solve the first riddle to unlock clue for Level 2
- Level 2: Intermediate puzzle with hints logic
- Level 3: Final treasure unlock with win animation
- Wrong answer = shake animation + hint
- Correct answer = confetti + next level

### ✨ Features:
- 3 Levels with progressive difficulty
- Clue validation logic
- Responsive Flutter Web UI
- Score + Timer system
- Hint system

### 🛠️ Tech Stack:
Flutter, Dart, Flutter Web, Provider

### 🚀 How to Run:
flutter pub get
flutter run -d chrome
